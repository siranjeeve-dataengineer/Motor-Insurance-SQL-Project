# Motor Insurance SQL Project

##  Project Overview
This project is a Motor Insurance Management System designed using MySQL. It focuses on creating a well-structured relational database to manage insurance users, customers, vehicles, policies, claims, payments, and add-on coverages.

##  Objectives
- Design a normalized insurance database
- Implement relationships between multiple entities
- Practice real-world SQL concepts
- Support insurance operations like policy issuance, claims, and payments

##  Technologies Used
- MySQL
- SQL
- MySQL Workbench

##  Database Details
- Database Name: `motor_insurance_policy`
- Number of Tables: 10
- Domain: Insurance / Finance

##  Tables Included
- `users` – System users and roles
- `regions` – Insurance operating regions
- `customers` – Customer information
- `vehicles` – Vehicle details
- `policies` – Insurance policies
- `quotes` – Policy quotations
- `payments` – Premium payments
- `claims` – Insurance claims
- `addoncoverage` – Add-on coverage details
- `policyaddon` – Policy and add-on mapping

##  SQL Concepts Used
- CREATE DATABASE & TABLE
- Primary and Foreign Keys
- Constraints (CHECK, UNIQUE)
- One-to-Many relationships
- Data normalization

##  Use Cases
- Track insurance policies per customer
- Manage claims and payments
- Associate vehicles with policies
- Apply add-on coverage to policies

##  How to Run the Project
1. Clone this repository
2. Open MySQL Workbench
3. Run the `sql project.sql` file
4. Explore tables and relationships
